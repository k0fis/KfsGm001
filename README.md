# KfsGm001

🎃 Halloween je kouzelný svátek plný strašidel, dýní a sladkostí! Slaví se 31. října.
    Děti si oblékají kostýmy čarodějnic, duchů nebo kostlivců a chodí po domech s košíky.
    Když zazvoní, řeknou: „Trick or treat!“ – to znamená „Dejte mi sladkost, nebo provedu lumpárnu!“ 🍬
    Lidé vyřezávají z dýní strašidelné obličeje a dovnitř dávají svíčku, aby krásně svítily.
    Je to večer plný smíchu, strašení a zábavy! 👻
